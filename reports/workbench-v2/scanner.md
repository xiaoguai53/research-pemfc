## 已核实的原始函数链

逐电流点调用原始 `Enernst_Calc`、`B_Calc`、`Eta_Act_Calc`、`Eta_Ohmic_Calc`、`Eta_Conc_Calc`、`Loss_Calc`、`Vcell_Calc` 与 `VStack_Calc`，即可得到任意测量电流点的原模型整堆电压。需要功率时继续使用 `Power_Calc` 和 `PowerStack_Calc`。不用改写方程或插值。

使用既有固定环境做了只读可行性检查：750 个官方电流点全部与完整 `Static_Analysis` 原始电压一致，最大绝对误差为 0；单独改变温度、氧分压、串联片数、电子电阻和 lambda 后，每种情形的 750 点也完全一致。零电流时原函数的三项损失本来就返回 0。该检查没有验证尚未实现的新生产封装。

每行实测温度可作为该点输入。它仍然是以测量边界条件为条件的准静态计算，不是求解出的空冷堆温。参数需要检查有限值、正确单位、正的气体分压/面积/膜厚/极限电流密度、正整数片数、非负电流和电阻，以及 `i < A × JMax`。lambda 必须在 14 至 23 内；上游 `filter_lambda` 会修改输入，且小于 14 时实际设为 23，因此不能将其当作生产中的输入修复。

## 建议的功能边界

| 功能 | 实际复用 | 关键交付 |
| --- | --- | --- |
| 实验数据检查 | pandas CSV/选定 XLSX sheet 与可追溯派生量 | 缺失/类型/范围检查、功率数据、图表、输入哈希 |
| 条件比较 | 明确实验单位后调用 SciPy paired/Welch API | 每个重复的聚合值、样本量、原单位效应、95%CI 与适用的 p 值 |
| Amphlett 校准 | 原始点函数链 + SciPy 有界 least_squares | 参数、优化状态、训练/留出误差、残差、可辨识性与边界诊断 |

校准属于用户要求的新增研究方法组合，OPEM 原仓库没有现成校准入口。应明确写明 SciPy 优化器与原模型分别承担什么任务，不能宣称该组合本来就是原论文的方法。建议首版只拟合原生电子电阻 R 和/或膜水含量 lambda；面积、膜厚、片数与气体分压须来自已知条件。

## 科学验证重点

1. 以原始 API 生成有明确已知参数的合成验证数据，并清楚标注不是实验数据；验证原始点链、参数恢复、改变输入和失败情况。
2. 响应值不能用于选择划分。提供 run/replicate ID 时，按完整组划分训练与留出集，并保存互斥 ID。若只有一条曲线，留出电流点只能标为插值检查，不是跨实验验证。只改变留出响应，拟合参数必须保持不变。
3. R 和 lambda 的效应可能高度相关。保存 Jacobian 秩、尺度化条件诊断与是否触及边界；优化器成功和低 RMSE 都不表示参数已被物理辨识。不要凭拟合残差自动给出可信参数区间。
4. 原始测量行在一次实验内可能是相关的时间样本。先按真实重复 ID 与工况聚合，再做 paired 或明确 `equal_var=False` 的 Welch 检验。配对按 ID 对齐，不按顺序或行号。缺失配对默认报错。
5. 在相同目标电流及明确容差内比较，导出两组实际电流范围。复制同一重复内的所有行不应改变推断样本量、效应和 CI。零方差/恒定差值应显式标记推断退化，不能输出 NaN/Infinity，或将其填成假的置信度。
6. 风机或其他辅机功耗缺失时，不能将它补成 0 并声称得到净功率。只有风机功耗时可标为“电堆总功率减已测风机功耗”，不等同于完整系统净功率。
7. 表格输入只读、不自动删除离群点、不暗中补值；选择 Excel 的 sheet 并保留名称。公式缓存缺失需要报告，不运行宏或从文件内容执行命令。

## 相关能力的风险提示

SALib Sobol 必须使用自己的有序设计与对应响应，不能把任意实测 CSV 塞入估计器；零响应方差应报告无法定义。输入独立均匀分布是分析假设，不是热水机理中的已知事实。

重建 Optuna 历史时要确认约束被原生完成处理记录；只在 add_trial 的 user_attrs 填一个数未必会生成采样器读取的约束状态。保留不满足约束的真实测量。低于启动试验数时要说明是随机起始阶段，候选实验没有已观察的性能结果。

当前没有对应源代码和验证数据的空冷热水动态、专利新颖性认证或因果机理判定保持未实现。产品可记录假设、数据、效应与已有技术证据，不应制造这些结论。
